## What this proves

- MV3 manifest loads without error in Chrome 144.
- Service worker boots and registers an `onMessage` listener.
- `chrome.runtime.sendMessage` round-trips between popup and service worker.
- `chrome.runtime.getURL` + `fetch` reads bundled `blacklist.json` from extension origin.
- Popup JS, CSS, and HTML render correctly.

## What this does NOT prove

These remain `[UNVERIFIED]`:

- Whether the Play API endpoints (`android.clients.google.com/fdfe/*`) accept CORS preflight from this extension origin with our `X-DFE-*` headers.
- Whether AuroraOSS dispenser POST succeeds from a browser origin.
- Whether `declarativeNetRequest` can inject the download `Cookie` header.
- Whether `chrome.downloads.download` handles multi-hundred-MB blob URLs.

Each will be proven by future entries in `docs/test-runs/` before any matching claim ships.
